# Politica di Sicurezza (Security Policy)

## Versioni Supportate

| Versione | Supportata          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Segnalazione di una Vulnerabilità

Se hai scoperto una potenziale vulnerabilità di sicurezza all'interno di questo repository, ti chiediamo di **non aprire un'issue pubblica**.

Invia una segnalazione privata ai maintainer tramite la funzione **GitHub Security Advisory** ("Report a vulnerability" nella scheda Security del repository) oppure via email al team di sviluppo.

Nel rapporto ti preghiamo di includere:
1. Una descrizione chiara della vulnerabilità.
2. I passaggi dettagliati per riprodurre il problema.
3. L'eventuale impatto sul sistema.

Ci impegniamo a rispondere e a valutare la segnalazione entro 48 ore lavorative.
